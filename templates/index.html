VIC Media Pipeline

Secure automated triage for suspected illicit digital media.

OPERATIONAL GUIDE:
  • Purpose: Rapidly screens digital evidence against known Project VIC hash databases to intercept illicit material before human review.
  • Cryptographic (SHA-256): Identifies exact, byte-for-byte matches of known contraband.
  • Perceptual (pHash): Detects visually similar images, even if they have been resized, cropped, or slightly altered by suspects.
  • Security: Files are hashed purely in-memory. Unmatched files are immediately dropped; matches trigger a CJIS audit log event.

Database Hash Ingestion

Extract and save hashes from confirmed illicit files to the local database.

OPERATIONAL GUIDE:
  • Purpose: Populates the local PostgreSQL database with new threat hashes.
  • Security: The physical file is hashed in memory and instantly discarded. Only the mathematical hashes are retained in the database.
